1

Слева API Keys → Create API Key → скопируй ключ (начинается с gsk_).

3

Вставь сюда

Ключ никуда не отправляется, кроме самих запросов к Groq.

VK-бот открытий

Бот в чате ловит «гороховая открыта» и пишет в контроль точек. 1) Сообщество VK → управление → работа с API → ключ сообщества и Callback API.
2) Cloudflare Worker (файл vk-bot-worker.js рядом с сайтом) — вставить URL в Callback.
3) Confirmation string и секрет из VK прописать в воркере.
Пока бота нет — в контроле тап по карточке отмечает точку открытой вручную.
