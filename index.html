Как включить AI
Нужен ключ Groq — один раз, хранится только на этом устройстве.
1

Зайди на сайт Groq

Открой console.groq.com и зарегистрируйся (Google / GitHub).

2

Создай API Key

Слева API Keys → Create API Key → скопируй ключ (начинается с gsk_).

3

Вставь сюда

Ключ никуда не отправляется, кроме самих запросов к Groq.
